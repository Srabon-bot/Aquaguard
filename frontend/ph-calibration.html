pH Calibration

Two-point calibration, done from any browser — no re-flashing the ESP32

← Back to dashboard

This page talks directly to your Firebase Realtime Database — the same one the ESP32 firmware (hardware/rebuild/07_full_reintegration/AquaGuard_v2.ino) uses. Before this page works, open ph-calibration.js and set FIREBASE_BASE_URL to your project's databaseURL (see hardware/FIREBASE_SETUP.md) — it's a plain constant near the top of the file, not a secret.

How this works

Fixed to two kitchen reference solutions — always the same two, so there's nothing to type in here:

🧪 Acid point

Plain white vinegar, 5% acidity — reference pH 2.4.

🧂 Base point

~1 tsp baking soda dissolved in 1 cup water — reference pH 8.3.

  1. Rinse the probe, dip it in the vinegar. Watch the live voltage below settle (stop drifting), then click Capture acid point.
  2. Rinse the probe, dip it in the baking soda solution. Wait for it to settle, then click Capture base point.
  3. Click Save calibration — this writes to the ESP32's flash and takes effect immediately, no reboot needed.

DIAGRAM 1
---------
Report: 1.1
PPT:    1.2

Title:
Edge Node Finite State Machine (Local Automation)

Purpose:
Shows the ESP32 local control logic and the Offline Edge Fail-Safe behavior.

Key project facts represented:
- Water Level >= 85 cm -> Drain Pump
- Water Level <= 40 cm -> Refill Pump
- TDS >= 600 ppm -> Water Exchange
- Abnormal pH -> local alert
- Feeder Servo -> scheduled feeding state
- Local Control Loop - No Internet Required

place the figure immediately after that explanation.

Suggested caption:

offline edge automation and fail-safe actuator operation."

3. REPORT FIGURE NUMBERING — VERY IMPORTANT
=========================================================

The filenames 1.1, 2.1, 3.1, and 5.1 are DIAGRAM IDs from the Claude
generation instructions.

They are NOT automatically the final report figure numbers.

Before inserting each report image:

1. Open the current List of Figures.
2. Check the figures already present in that chapter.
3. Decide whether the new diagram replaces an existing figure or is an
   additional figure.
4. Assign the next correct sequential figure number.
5. Update every in-text reference to that figure.
6. Update the List of Figures.
7. Update the Table of Contents/page numbers if required.

DO NOT create duplicate Figure 3.1, Figure 3.2, Figure 5.1, etc.

4. IMAGE INSERTION FORMAT
=========================================================

For each REPORT diagram:

B. Insert the image.

G. Update the List of Figures.

Figure X.X."
